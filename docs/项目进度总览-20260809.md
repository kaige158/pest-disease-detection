### 数据飞轮（已建成）

```
Flutter拍照 → 图片质量检测 → Gemini识别 → 置信度策略
     ↓
diagnosis_record (全字段入库: AI原始响应+解析结果+置信度+Provider+耗时)
     ↓
用户反馈(✅/❌) → POST API → user_feedback入库
     ↓
专家审核 → expert_reviewed → evaluation_record
     ↓
AI Benchmark → 按作物/按病害/按置信度准确率报告
     ↓
训练数据资产（持续积累中）
```

## 三、技术架构

```
┌──────────────────────────────────────────────┐
│                Flutter 移动端                  │
│  蔬菜版APP ←→ 共享核心(80%) ←→ 果树版APP       │
│  (拍照→质量检测→AI识别→结果展示→反馈→离线库)     │
└──────────────────┬───────────────────────────┘
                   │ REST API
┌──────────────────┴───────────────────────────┐
│          Spring Boot 3 业务后端                │
│  用户系统 / 识别入库 / 知识库 / 反馈 / 审核     │
│  EvaluationService / AI评估统计               │
└──────────────────┬───────────────────────────┘
                   │ HTTP
┌──────────────────┴───────────────────────────┐
│        FastAPI Python AI 服务                  │
│  ┌──────────────────────────────────────┐    │
│  │    质量检测 → Provider → 置信度策略    │    │
│  │  OpenAI│Claude│Gemini✅│Kimi│Custom   │    │
│  └──────────────────────────────────────┘    │
│  Parser → Benchmark → 训练数据导出             │
└──────────────────────────────────────────────┘
                   │
    PostgreSQL 16  +  Redis 7  +  本地文件存储
```
