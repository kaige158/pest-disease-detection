## 二、技术架构

```
┌──────────────────────────────────────────────┐
│                Flutter 移动端                  │
│  蔬菜版APP ←→ 共享核心(80%) ←→ 果树版APP       │
│  (拍照上传 / AI结果展示 / 双语切换 / 离线库)      │
└──────────────────┬───────────────────────────┘
                   │ REST API
┌──────────────────┴───────────────────────────┐
│          Spring Boot 3 业务后端                │
│  用户系统 / 知识库CRUD / 识别记录 / 配置中心     │
└──────────────────┬───────────────────────────┘
                   │ HTTP
┌──────────────────┴───────────────────────────┐
│        FastAPI Python AI 服务 (微服务)          │
│  ┌──────────────────────────────────────┐    │
│  │        Provider 抽象层               │    │
│  │  OpenAI │ Claude │ Gemini │ Kimi │Custom │ │
│  └──────────────────────────────────────┘    │
│  Parser → DiagnosisResult(标准化)              │
└──────────────────────────────────────────────┘
                   │
    PostgreSQL 16  +  Redis 7  +  本地文件存储
```

| 层级 | 技术 | 代码量 |
|------|------|:--:|
| 移动端 | Flutter 3.29 + Dart | 14个文件 |
| 业务后端 | Spring Boot 3 + Java 17 | 37个Java文件 |
| AI服务 | FastAPI + Python 3.13 | 30个Python文件 |
| 数据库 | PostgreSQL 16 (3层Schema) | 2个SQL脚本 |
| 部署 | Docker Compose (5容器) | 完整配置 |
| **文档** | 设计/运营/数据/部署/交付 | **16份专业文档** |
