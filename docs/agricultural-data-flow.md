## 四、数据质量分级

| 等级 | 条件 | 用途 |
|------|------|------|
| **S级 (黄金)** | 专家标注确认 + 图片清晰 + 元数据完整 | 训练集核心样本 |
| **A级 (银)** | AI高置信度 + 用户确认 + 图片清晰 | 训练集补充样本 |
| **B级 (铜)** | AI中置信度 + 专家审核通过 | 验证集 |
| **C级 (参考)** | 低置信度 + 专家修正 | 困难样本(难例挖掘) |
| **D级 (废弃)** | 图片模糊/无法判断/标注存疑 | 不参与训练 |

### 质量筛选SQL

```sql
-- 导出S级训练数据
SELECT di.*
FROM disease_image di
JOIN expert_review er ON di.id = er.disease_image_id
WHERE di.is_usable = TRUE
  AND di.image_quality_score >= 0.7
  AND er.review_action = 'verified'
  AND di.approval_status = 'approved'
ORDER BY di.created_at DESC;
```

## 五、数据积累里程碑

| 里程碑 | 数据量 | 能做什么 | 预计时间 |
|--------|--------|----------|----------|
| M1: 冷启动 | 0-500张 | 仅靠老师初始语料 + AI API | 0-1月 |
| M2: 初步可用 | 500-1500张 | 优化AI Prompt + 建立baseline | 1-3月 |
| M3: 验证达标 | 1500-3000张 | 构建验证集 + 评估AI效果 | 3-6月 |
| M4: 训练就绪 | 3000-5000张 | 可训练简单分类模型 | 6-9月 |
| M5: 高质量集 | 5000+ 张 | 训练专属模型 + 论文发表 | 9-12月 |

## 七、AI模型反馈闭环

```
当前: API调用模式 (不需训练)
    │
    ▼
数据积累到3000+张 → 可考虑训练专属模型

训练流程(未来):
┌──────────────────────────────────────────────────────┐
│ 1. 从disease_image导出S级+A级数据                     │
│    ↓                                                  │
│ 2. 数据增强(旋转/翻转/亮度/对比度)                    │
│    ↓                                                  │
│ 3. 划分训练集(70%)/验证集(15%)/测试集(15%)          │
│    ↓                                                  │
│ 4. 训练YOLO/ResNet/EfficientNet分类模型              │
│    ↓                                                  │
│ 5. 评估: 准确率 vs API baseline                      │
│    ↓                                                  │
│ 6. 如果模型效果更好 → 替换API为本地模型               │
│    ↓                                                  │
│ 7. 部署: ONNX/TensorRT → Python AI Service           │
│    ↓                                                  │
│ 8. 持续收集新数据 → 定期重新训练                      │
└──────────────────────────────────────────────────────┘

模型版本管理:
model_version 表记录:
├── version: v1.0, v1.1, v2.0...
├── base_model: ResNet50 / YOLOv8 / EfficientNet-B3
├── training_data_count: 训练数据量
├── accuracy: 准确率
├── f1_score: F1分数
├── deployed_at: 部署时间
└── is_active: 当前是否在使用
```

## 八、数据安全与隐私

| 层面 | 措施 |
|------|------|
| **用户匿名化** | 游客模式无需注册，注册也只需手机号 |
| **GPS脱敏** | 精确到乡镇级别即可(非精确坐标) |
| **数据归属** | 老师作为数据资产所有者(在专家后台管理) |
| **导出控制** | 所有数据导出记录在data_export_log |
| **删除权** | 用户可请求删除自己的上传记录 |

## 九、数据闭环中的角色分工

| 角色 | 贡献的数据 | 获得的价值 |
|------|-----------|-----------|
| **农户** | 拍照图片 + GPS + 反馈(✅/❌) | 免费诊断 + 防治方案 |
| **技术员** | 批量采集数据(高质量) | 工作效率提升 + 数据报告 |
| **老师** | 初始语料 + 专家标注 + 知识录入 | 数据资产 + 科研成果 + 平台运营 |
| **AI** | 自动标注(初始) | 被修正后提升准确率 |
