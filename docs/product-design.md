## 2. 使用场景

### 场景1：老挝农民发现菜叶异常
```
1. 农民在菜地发现白菜叶片有黄斑
2. 打开APP → 点击"拍照识别"（大按钮，老挝语标注）
3. 拍照 → 等待3-8秒 → 显示结果
4. 结果展示：
   - 病虫害名称（老挝语大字 + 中文小字）
   - 置信度百分比
   - 3-5张参考图片对比
   - 防控措施（农药名称 + 老挝语说明）
5. 可截图分享给邻居或技术员
```

### 场景2：技术员下乡诊断
```
1. 技术员携带手机到农田
2. 打开APP → 切换中文界面
3. 使用"批量识别"模式（连续拍照）
4. 每拍一张自动记录GPS位置
5. 晚_上回到办公室 → 导出诊断报告
6. 数据自动上传到科研数据库
```

### 场景3：老师课堂展示/科研汇报
```
1. 老师打开管理后台
2. 查看数据看板：
   - 累计识别次数
   - 病虫害分布热力图
   - 各地区主要病虫害统计
3. 导出数据用于论文/报告
4. 展示APP功能（两个版本：蔬菜/果树）
```

## 5. 离线能力设计

### 5.1 离线场景

老挝网络环境不稳定 → APP必须有离线能力。

```
┌─────────────────────────────────────────────────────────┐
│                    离线能力分层                           │
│                                                          │
│  L1: 完全离线可用                                        │
│  ┌────────────────────────────────────────────────┐     │
│  │ • 知识库浏览 (内置100+病虫害基础信息+图片)        │     │
│  │ • 作物分类浏览                                   │     │
│  │ • 收藏内容查看                                   │     │
│  └────────────────────────────────────────────────┘     │
│                                                          │
│  L2: 弱网可用                                            │
│  ┌────────────────────────────────────────────────┐     │
│  │ • 图片压缩后上传 (原图压缩到300KB以内)             │     │
│  │ • 识别请求超时重试 (3次)                         │     │
│  │ • 排队上传 (网络恢复后自动重传)                   │     │
│  └────────────────────────────────────────────────┘     │
│                                                          │
│  L3: 必须联网                                            │
│  ┌────────────────────────────────────────────────┐     │
│  │ • AI拍照识别 (需要调用云端AI API)                 │     │
│  │ • AI诊断Agent对话                                │     │
│  │ • 知识库内容更新                                  │     │
│  └────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────┘
```

### 5.2 离线数据同步策略

```
APP内置初始离线DB (随APP打包)
    │
    └──→ 首次启动: 加载内置数据
            │
            └──→ 联网时: 检查更新 → 增量下载 → 合并
                    │
                    └──→ 更新时间戳记录，下次只拉增量
```

## 6. 用户体系设计

### 6.1 用户模型

```
User
├── id (UUID)
├── phone (手机号, 可选, 老挝格式)
├── nickname
├── language_preference (zh/lo)
├── region (省份/地区 — 重要！)
│   ├── 北部: 琅勃拉邦、丰沙里...
│   ├── 中部: 万象、波里坎赛...
│   └── 南部: 占巴塞、沙拉湾...
├── crop_preferences (偏好作物类型, 用于推荐)
├── role (guest/farmer/technician/admin)
├── created_at
└── last_login_at
```

### 6.2 注册流程（极简）

```
方案A (推荐): 游客模式
  - 无需注册即可使用核心功能（拍照识别 + 离线知识库）
  - AI助手限次：5次/天
  - 不记录历史

方案B: 手机号注册
  - 验证码登录（类似WhatsApp）
  - 解锁完整功能

方案C: 微信/Google登录 (后期)
  - 老挝用户有微信吗？待调研
```

## 7. 数据采集与科研价值设计

### 7.1 每次识别都是一次数据采集

```
用户拍照 → 上传图片 → AI识别 → 返回结果
                │
                └──→ 后台自动记录:
                     ├── 图片 (原图存储)
                     ├── GPS位置
                     ├── 时间戳
                     ├── AI识别结果
                     ├── 用户确认/修正 (可选)
                     ├── 作物类型
                     └── 天气数据 (通过API获取)
```

### 7.2 数据资产积累路径

```
第1-3个月: 积累基础识别数据
    └──→ 第4-6个月: 数据清洗 + 人工标注修正
        └──→ 第7-12个月: 数据集达到可训练规模
            └──→ 未来: 训练专属老挝病虫害模型
```
