### 3.4 专家审核流程

```
用户拍照上传
    │
    ▼
AI自动识别 → 存入recognition_record (status=pending_review)
    │
    │  高置信度(≥90%) → 自动通过，标记为auto_approved
    │  中置信度(70-89%) → 进入审核队列
    │  低置信度(<70%) → 进入审核队列 + 标记为priority
    │
    ▼
专家后台审核
    │
    ├──→ AI正确: 确认通过 → 标记expert_verified
    │       └──→ 图片入库 disease_image (可用于训练)
    │
    ├──→ AI错误: 专家修正标注 → 标记expert_corrected
    │       └──→ 图片入库 + AI标注记录修正
    │
    └──→ 图片质量差/无法判断 → 标记rejected + 原因
```

### 飞轮启动策略

```
阶段1 (0-3个月): 冷启动
  - 依赖老师提供的初始语料 (100+种病虫害)
  - AI API直接识别
  - 专家审核每一条结果
  - 目标: 积累1000张高质量标注图片

阶段2 (3-6个月): 加速
  - 专家审核率降低到30% (高置信度自动通过)
  - 数据开始反哺系统 (更新提示词/优化匹配)
  - 目标: 积累3000张标注图片, 识别准确率提升5%

阶段3 (6-12个月): 自运转
  - 专家抽检式审核 (5-10%)
  - 数据足够训练专属模型
  - 目标: 积累5000+张标注图片, 训练老挝专属模型
```

## 七、老师运营流程

> 老师不是程序员，不能让她直接操作数据库。需要设计一个她能理解的日常运营流程。

### 7.1 老师日常运营（每周 1-2 小时）

```
┌────────────────────────────────────────────────────────────┐
│                    老师周运营流程                            │
│                                                            │
│  周一:                                                      │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 1. 登录管理后台                                       │  │
│  │ 2. 查看上周数据摘要:                                 │  │
│  │    - 新增用户数                                       │  │
│  │    - 识别次数                                         │  │
│  │    - 待审核图片数                                     │  │
│  │ 3. 审核待处理AI结果 (通常10-30条)                    │  │
│  │    - 逐条查看图片 → AI结果正确? → 确认/修正          │  │
│  │    - 标注图片质量 + 严重程度                          │  │
│  │ 4. 查看用户反馈 (如果有)                             │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  周三/周四:                                                 │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 1. 检查知识库内容完整性                               │  │
│  │    - 是否有新的病虫害需要添加?                        │  │
│  │    - 老挝语翻译是否有缺失?                            │  │
│  │ 2. 补充/编辑知识条目                                  │  │
│  │ 3. 回复用户反馈                                       │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  月末:                                                      │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 1. 生成月度报告:                                      │  │
│  │    - 本月识别统计                                     │  │
│  │    - 病虫害分布情况                                   │  │
│  │    - 数据资产增长                                     │  │
│  │ 2. 导出数据 (用于科研/汇报)                          │  │
│  │ 3. 检查系统运行状态                                   │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

### 7.2 老师语料入库流程

```
老师获得新语料 (图片+文本)
    │
    ▼
┌──────────────────────────────────────────────────────────┐
│ 途径1: 批量导入 (推荐)                                    │
│ 老师整理 Excel 表格 → 上传到管理后台 → 系统自动入库       │
│                                                          │
│ 途径2: 逐条录入                                          │
│ 管理后台 → 新增病虫害 → 填写表单 → 上传图片 → 发布        │
│                                                          │
│ 途径3: 田野采集入库                                      │
│ 技术员用APP拍照(GPS自动记录) → AI预标注 → 老师审核确认    │
└──────────────────────────────────────────────────────────┘
```

### 7.3 老师需要的三个核心操作

| 操作 | 频率 | 耗时 | 说明 |
|------|------|------|------|
| **AI结果审核** | 每周1-2次 | 15-30分钟 | 审核待确认的识别结果，修正AI错误 |
| **知识库维护** | 按需 | 不定 | 新增/修改病虫害信息、补充老挝语翻译 |
| **数据导出** | 每月/按需 | 5分钟 | 导出统计数据用于科研报告/论文 |
