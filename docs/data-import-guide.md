## 一、数据导入方式

### 方式1：Excel批量导入（推荐）

老师只需填写Excel表格，系统自动导入。提供3个模板文件：

#### 模板1: 作物列表.xlsx

| 版本 | 分类 | 中文名 | 老挝语名 | 学名 | 简介(中文) | 简介(老挝语) | 种植信息 |
|------|------|--------|----------|------|-----------|-------------|---------|
| vegetable | 茄果类 | 辣椒 | ໝາກເຜັດ | Capsicum annuum | 老挝重要蔬菜... | ... | 播种期11-2月 |
| fruit | 热带果树 | 芒果 | ໝາກມ່ວງ | Mangifera indica | 老挝传统果树... | ... | 株距5×5m |

> **版本列**只能填: `vegetable`(蔬菜) 或 `fruit`(果树)

#### 模板2: 病虫害列表.xlsx

| 版本 | 作物中文名 | 病虫害中文名 | 老挝语名 | 学名 | 类型 | 严重程度 | 症状(中文) | 症状(老挝语) | 发病条件 | 标签 |
|------|-----------|-------------|----------|------|------|---------|-----------|-------------|---------|------|
| vegetable | 辣椒 | 辣椒炭疽病 | ພະຍາດ... | Colletotrichum | disease | severe | 果实出现水渍状斑点... | ... | 25-28°C高湿 | 炭疽,果腐 |

> **类型列**只能填: `disease`(病害) 或 `pest`(虫害)
> **严重程度**只能填: `mild`(轻微) / `moderate`(中等) / `severe`(严重)
> **标签列**用逗号分隔搜索关键词

#### 模板3: 防控方案.xlsx

| 病虫害中文名 | 防治类型 | 措施名称(中文) | 措施名称(老挝语) | 用法说明(中文) | 用法说明(老挝语) | 注意事项 |

| 辣椒炭疽病 | chemical | 70%甲基托布津800倍液 | ຢາ... | 每7天喷1次 | ສີດທຸກໆ7ມື້ | 采收前14天停用 |

> **防治类型**只能填: `chemical`(化学) / `biological`(生物) / `physical`(物理) / `cultivation`(栽培)

## 二、图片文件组织规范

### 文件命名规则

```
{作物名}_{病虫害名}_{编号}.jpg

例如:
pepper_anthracnose_001.jpg    (辣椒炭疽病)
tomato_late_blight_001.jpg     (番茄晚疫病)
mango_anthracnose_001.jpg      (芒果炭疽病)
```

### 目录结构

```
语料图片/
├── vegetable/
│   ├── 辣椒/
│   │   ├── 炭疽病/
│   │   │   ├── pepper_anthracnose_001.jpg
│   │   │   └── pepper_anthracnose_002.jpg
│   │   ├── 白粉病/
│   │   └── ...
│   ├── 番茄/
│   ├── 黄瓜/
│   ├── 白菜/
│   └── 茄子/
└── fruit/
    ├── 香蕉/
    ├── 芒果/
    └── 柑橘/
```

### 图片要求

| 要求 | 说明 |
|------|------|
| 格式 | JPG或PNG |
| 大小 | 建议 200KB-2MB |
| 分辨率 | 800×600以上 |
| 内容 | 病虫害症状清晰可见 |
| 数量 | 每种病虫害 5-20张 |
| 拍摄部位 | 叶片/果实/茎秆/整株 |

## 五、图片导入命令

> 老师准备好图片后，运行以下命令导入：

```bash
# 1. 将图片文件夹放到项目目录下
# 2. 运行导入脚本
cd spring-backend
python ../scripts/import_images.py \
  --image-dir ../语料图片/ \
  --version vegetable \
  --source TEACHER_DATA
```

导入脚本会自动：
- 读取图片
- 计算SHA256去重
- 关联到对应的病虫害ID
- 入库 disease_image 表
