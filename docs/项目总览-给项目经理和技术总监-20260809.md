## 二、项目定位与产品形态

| 维度 | 说明 |
|------|------|
| **项目定位** | 面向老挝农民的农业病虫害AI诊断 + 知识服务平台 |
| **交付物** | 蔬菜版APP + 果树版APP（共享80%代码，独立打包） |
| **目标平台** | Android + iOS（Flutter跨平台） |
| **目标用户** | 老挝本地农民 / 农业技术人员 |
| **运营模式** | 农业专家运营、持续积累数据资产、AI越用越准 |
| **核心竞争力** | 农业数据资产 → 训练专属模型 → 东盟农业AI壁垒 |
| **语料来源** | 老师提供（中文+老挝语双语图片、文本、病虫害数据） |

### 为什么做APP而非小程序

微信小程序在老挝等海外地区使用受限（无法使用或卡顿），本地APP只需下载安装即可使用，不受平台限制。

## 七、数据闭环（AI数据飞轮）

```
Flutter拍照 → 图片质量检测 → Gemini AI识别 → 置信度策略分级
     ↓
diagnosis_record 全字段入库
 (AI原始响应 + 解析结果 + 置信度 + Provider + 耗时 + 图片质量评分)
     ↓
用户反馈 (✅正确 / ❌不正确 / ⚠️存疑) → POST API → user_feedback入库
     ↓
专家审核 → expert_reviewed → evaluation_record
     ↓
专家审核通过 → training_ready = true → 训练数据就绪
     ↓
AI Benchmark → 按作物/按病害/按置信度 准确率报告
     ↓
训练数据导出 → YOLO/MobileNet标注格式
     ↓
未来：训练专属农业视觉模型（"教师模型"Gemini → "学生模型"YOLO）
```

**核心理念：** 使用越多 → 数据越多 → AI越准 → 价值越高。核心资产不是APP，而是农业数据。
