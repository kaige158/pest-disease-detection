## 一、老师的三重身份

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  身份1: 知识生产者                                        │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 做什么: 录入病虫害知识、补充防治方案、上传案例图片    │  │
│  │ 产出: 农业知识库 (中老双语)                         │  │
│  │ 价值: APP内容来源，农民查询的答案                   │  │
│  └────────────────────────────────────────────────────┘  │
│                                                          │
│  身份2: AI审核者                                          │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 做什么: 审核AI识别结果、修正错误标注                  │  │
│  │ 产出: 高质量标注数据                                │  │
│  │ 价值: 数据闭环关键环节，训练数据来源                 │  │
│  └────────────────────────────────────────────────────┘  │
│                                                          │
│  身份3: 数据资产管理者                                    │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 做什么: 查看统计、导出报告、管理数据资产              │  │
│  │ 产出: 科研报告/论文/国际合作成果                     │  │
│  │ 价值: 项目可持续运营的基础                          │  │
│  └────────────────────────────────────────────────────┘  │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 3.3 快捷审核模式（批量操作）

```
高置信度(≥90%) 一键批量确认:

系统自动筛选出置信度≥90%的待审核条目 → 老师一键确认
→ 适用于AI高度自信的情况，节省老师时间

老师在列表中勾选:
☑ 番茄晚疫病 92%
☑ 芒果炭疽病 95%
☑ 黄瓜霜霉病 91%
...
[一键确认(12条)] → 12条直接标记为 expert_verified
```

## 七、老师每周工作流总结

| 时间 | 做什么 | 耗时 | 工具 |
|------|--------|------|------|
| **周一** | 审核上周AI结果 | 15-20分钟 | AI审核中心 |
| **周三** | 维护知识库（按需） | 0-30分钟 | 知识库管理 |
| **周五** | 查看本周数据 | 5分钟 | 数据看板 |
| **月末** | 导出月度报告 | 10分钟 | 数据导出 |
| **有新材料时** | 录入新病虫害/翻译 | 30-60分钟 | 知识库+双语管理 |

**合计：** 每周约30分钟，每月约2小时。可接受。
