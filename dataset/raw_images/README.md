# 农业病虫害测试图片目录

> 将真实病虫害照片放在此目录下，文件名与 labels.json 中的 image 字段对应。

## 图片要求

| 要求 | 说明 |
|------|------|
| 格式 | JPG / PNG / WEBP |
| 分辨率 | 建议 800×600 以上 |
| 内容 | 清晰可见的病害症状（叶片/果实/茎部） |
| 标注 | 每张图片需有专家确认的正确病害名 |
| 命名 | `{作物}_{序号}.jpg`，如 `tomato_001.jpg` |

## 示例文件

```
raw_images/
├── tomato_001.jpg    # 番茄晚疫病
├── tomato_002.jpg    # 番茄早疫病
├── chili_001.jpg     # 辣椒炭疽病
├── cabbage_001.jpg   # 白菜霜霉病
└── ...
```

## 数据收集优先级

1. **第一优先**: 老挝常见蔬菜病害（番茄/辣椒/白菜/黄瓜/豆类）
2. **第二优先**: 老挝常见果树病害（芒果/香蕉/荔枝/柑橘）
3. **第三优先**: 虫害照片
4. **第四优先**: 生理性病害（缺素/日灼等）
